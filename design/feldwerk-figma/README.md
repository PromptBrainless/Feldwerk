# Feldwerk — Design System

Quelle: https://feldwerk.grok.me  
Produkt: Singleplayer-Rollenspiel mit Editor (Spielen / Zeichnen). Raster T = 64, Karte 20 × 14.

Schrift: Fraunces (Wortmarke) · Outfit (UI).

## App-Struktur

- Modi: Spielen, Zeichnen
- Karten: Anger, Teich, Stube
- Zeichnen-Werkzeuge: Pinsel, Radierer, Sperre, Hand
- Schichten: Boden, Objekte
- Kategorien: Alle, Boden, Dorf, Wasser, Wald, Häuser, Möbel, Deko, Figuren, Rahmen, Eigene, Weg
- Statusleiste: Bereit · Kartenname · 64 px
